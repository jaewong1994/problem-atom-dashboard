# 세미나 자산 현황판

`현황판_시작.cmd`를 더블클릭하면 브라우저에서 현황판이 열립니다. `index.html`을 직접 열면 공유 JSON 저장은 작동하지 않습니다.

현황판 상단의 `프로젝트 비전 · 원자 조합 데모`를 누르면 `vision.html`이 열립니다. 프로젝트 목적, 16회 검증 게이트, 기출 분석 가능성, 개정 교육과정 대응 이유와 샘플 원자 조합 실험을 한 페이지에서 볼 수 있습니다.

## 구성원 사용법

1. 이 `dashboard` 폴더 전체를 OneDrive 등으로 공유합니다.
2. 각 구성원은 동기화가 끝난 뒤 `현황판_시작.cmd`를 실행합니다.
3. 발표할 사람은 자신의 이름 또는 별칭을 입력합니다. 구성원마다 서로 다른 이름을 사용합니다.
4. 자신이 발표한 문항만 체크합니다. 같은 문항을 여러 명이 발표하면 이름이 모두 표시됩니다.
5. 상단에서 `평가원`, `교육청 학력평가`를 전환합니다. 평가원 탭에는 6·9월 모의평가와 수능이 함께 표시됩니다.
6. `문제 펼치기`가 있는 문항은 클릭할 때만 로컬 KaTeX로 본문을 렌더링합니다. 목록에서는 카드가 작게 유지됩니다.

체크 기록은 `progress/구성원이름.json`에 저장됩니다. 구성원별 파일을 분리했기 때문에 동시에 체크해도 하나의 파일을 서로 덮어쓰지 않습니다. 한 사람이 체크를 해제해도 다른 발표자의 기록은 유지됩니다. 화면은 5초마다 동기화된 JSON을 다시 읽습니다.

## 운영자 전용

- `dashboard-data.json`: 시험, 공통 문항, 선택과목 문항 목록입니다. 같은 이름으로 교체하면 화면이 자동으로 다시 읽습니다.
- `build_dashboard.py`: NGD2의 2016~2025 평가원 6·9월 JSON/PNG 읽기 전용 자산과 별도 수능 HWP 파일 목록을 이용해 초기 데이터를 다시 만듭니다.
- 2006~2015 HWP는 OCR하지 않았습니다. 현재 30개 문항 체크 틀만 제공하며 배점은 `미분류`입니다. 운영자가 OCR·검수한 메타를 `dashboard-data.json`에 넣으면 3점·4점 필터와 4점 완료율이 즉시 활성화됩니다.
- 수능은 2007~2026학년도 20개년 HWP 파일을 확인해 체크 틀만 만들었습니다. OCR은 수행하지 않았고, 2022학년도 이후는 공통 1~22번을 한 번만 두고 선택과목 23~30번만 분리했습니다.
- 교육청 탭은 현재 빈 상태입니다. 이후 시험 데이터에 `examGroup: "education"`을 넣으면 같은 UI에 나타납니다.

## 데이터 규칙

시험 박스는 `연도+시행월` 단위이며 내부에 공통·선택과목 `sections`가 있습니다. 각 문항은 다음 필드를 사용합니다.

```json
{
  "id": "kice-2025-6-미적분-30",
  "number": 30,
  "score": 4,
  "unit": "미적분",
  "body": "함수 $f(x)$에 대하여 …",
  "preview": "assets/questions/kice-2025-6-미적분/item_030.png",
  "legacyIds": ["kice-2025-6-미적분-30"]
}
```

시험에는 시험 유형인 `examGroup`(`mock`, `csat`, `education`)과 주관기관인 `organizer`가 별도로 들어갑니다. `id`는 한 번 체크 기록이 생기면 바꾸지 않습니다. 공통 문항의 `legacyIds`에는 기존 기하·미적분·확통 박스에서 쓰던 ID를 모두 넣어 이전 기록을 합칩니다. `score`는 `3`, `4`, 또는 미분류를 뜻하는 `null`입니다. `body`는 `$...$` 구분자를 쓰는 LaTeX 포함 원문이며, `preview`는 현황판 폴더 기준 상대경로입니다. 자료가 없으면 각각 `null`입니다.
