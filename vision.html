기출 4점 풀이를 나눠 기록하고,
그 기록으로 새 문제를 만든다.

수학강사 4~5명이 매주 기출을 풀고 토론합니다. 문항마다 풀이를 움직인 조건, 관찰, 표현 전환, 계산, 실수 지점을 기록합니다. AI는 이 기록을 검색하고 조합해 새 문제 초안을 만들고, 강사가 최종 검수합니다.

NGD2와는 별도 프로젝트입니다. 현재는 기출 원문을 읽기 전용으로 가져오며, 나중에 연결할 수 있게 데이터 형식만 맞춥니다.

01 / 매주 할 일

세미나 한 번에
4문항을 끝낸다

구성원은 풀이와 토론에만 집중합니다. 스캔, OCR, 데이터 입력, JSON 반영은 운영자가 세미나 뒤에 처리합니다.

세미나 전 · 각자 20~30분

맡은 문제를 풀어 온다

  • 정답보다 먼저 풀이가 시작된 지점을 표시
  • 막히기 쉬운 지점과 다른 풀이를 메모
  • 같은 문제를 여러 명이 맡아도 됨
세미나 · 100분

문항마다 결론을 남긴다

  1. 10분오늘 다룰 4문항과 발표자 확인
  2. 80분문항당 20분씩 풀이 비교와 원자 확정

02 / 회차별 계획

4문항씩 계속하면
여기까지 간다

아래 숫자는 주 1회, 회당 4문항을 끝낸다는 기준입니다. 문항 수보다 검수 완료 여부가 우선이며, 품질이 떨어지면 다음 단계로 넘어가지 않습니다.

시점누적 문항그때 할 수 있는 일다음 단계로 가는 기준
4회
약 1개월16문항

같은 풀이를 같은 이름으로 부르도록 태그와 원자 작성 규칙을 고칩니다.

같은 문항을 두 사람이 분석했을 때 핵심 원자 80% 이상 일치
8회
약 2개월32문항

같은 단원 안에서 반복되는 원자를 찾고, 중복 이름을 하나로 합칩니다.

승인 원자의 25% 이상이 서로 다른 문항에서 다시 발견됨
16회
약 4개월64문항

한 단원을 골라 원자 2~4개를 조합한 새 문제 초안을 처음 만듭니다.

새 문제 20개 중 수학 오류 없이 한 번 수정 후 쓸 수 있는 문제가 12개 이상
32회
약 8개월128문항

처음 보는 기출을 스캔하면 사용된 원자 후보와 비슷한 기출을 보여주는 검색 기능을 시험합니다.

미분석 50문항 중 45문항 이상에서 강사가 지정한 원자가 검색 결과 5개 안에 포함
52회
약 1년208문항

주요 단원별로 쉬운형, 표준형, 고난도형 문제 묶음을 사람이 검수해 제작합니다.

30문항 난이도 예측 중 강사 판단과 한 단계 이내로 맞는 문항 24개 이상
100회
약 2년400문항

단원을 넘나드는 원자를 골라 개정 교육과정용 융합 문제와 교재 한 단원을 제작합니다.

내부 검수, 다른 강사의 출처 비공개 풀이, 원문 유사도 검사를 모두 통과한 출판 후보 100문항 이상

예상 원자 수를 목표로 잡지 않습니다. 같은 원자는 합치고, 다른 문제에서 다시 확인된 원자만 유지합니다. 많이 만드는 것보다 다시 쓸 수 있는 원자를 남기는 것이 기준입니다.

03 / 최종 결과

교사가 조건을 고르면
AI가 문제 초안을 만든다

최종 목표는 자동 출제가 아닙니다. 검증된 기출 풀이 요소를 골라 난이도와 계산량을 지정하면 AI가 초안을 만들고, 수학강사가 검수해 교재와 문제은행에 쓸 수 있게 하는 것입니다.

  1. 1
    새 문제 스캔운영자가 OCR로 문장과 수식을 읽음
  2. 2
    사용 원자 찾기비슷한 기출과 원자 후보 5개를 제시
  3. 3
    강사가 확정맞는 원자를 고치고 빠진 원자를 추가
  4. 4
    제작 조건 선택단원, 배점, 목표 등급, 계산량, 풀이 시간 입력
  5. 5
    AI가 초안 제작호환되는 원자를 연결해 문제와 해설 생성
  6. 6
    사람이 검수정답, 조건, 교육과정, 원문 유사도를 확인하고 승인
먼저 완성

기출 분석 자료실

문항, 발표자, 원자, 풀이 순서, 난이도와 실수 지점을 검색합니다.

검증 후 완성

문제 제작 도구

원자와 목표 난이도를 고르면 AI가 문제와 해설의 첫 초안을 만듭니다.

장기 결과

교재와 문제은행

검수 통과 문항만 모아 수능 대비, 내신 대비, 융합형 세트로 배포합니다.

04 / 100% 분석의 뜻

모든 기출을
분석할 수 있을까?

모든 기출을 기존 원자만으로 억지로 맞추지는 않습니다. 처음 보는 풀이가 나오면 새 원자로 등록합니다. 목표는 자동으로 100% 맞히는 것이 아니라, 모든 문항을 기존 원자, 수정 필요, 새 원자 필요 중 하나로 빠짐없이 분류하는 것입니다.

이 검사를 통과하면 “기출 분석 가능”으로 판정합니다.

  1. 미분석 100문항을 준비세미나에 쓰지 않은 평가원 4점 문항으로 검사
  2. 원자 후보를 자동 검색각 문항마다 가능성 높은 원자 5개와 근거 구간 제시
  3. 강사가 정답표 작성검색 결과를 보지 않고 필요한 원자를 직접 확정
  4. 90문항 이상 맞으면 통과정답 원자가 후보 5개 안에 있고, 나머지도 새 원자로 설명 가능해야 함

금지할 주장: “AI가 모든 문제를 자동으로 이해한다.”
허용할 주장: “강사가 확인할 수 있는 원자 후보와 비슷한 기출을 빠르게 찾는다.”

06 / 직접 조합해 보기

원자를 고르고
난이도를 바꿔 본다

아래 카드는 데모용입니다. 원자 2~4개를 고른 뒤 단서, 경우 수, 계산량을 바꾸면 AI에 전달할 제작 조건이 만들어집니다.

1
사용할 원자카드를 눌러 2~4개 선택
2
바꿀 조건풀이 핵심은 유지하고 부담을 조절
3
AI에 전달할 제작 조건선택에 따라 바로 갱신

현재 상태: 검수 전 초안다음: AI 제작 → 수학 검수 → 다른 강사가 출처를 보지 않고 풀이

07 / 방향을 지키는 규칙

계속 고치되
목표는 바꾸지 않는다

매 4회마다 기록 방식과 태그는 고칩니다. 그러나 기출 풀이를 재사용 가능한 단위로 기록하고, 그 기록으로 새 문제를 만든다는 목표는 고정합니다.

계속할 것
  • 기출 풀이 근거를 문항과 함께 보관
  • 같은 원자는 합치고 차이를 기록
  • 사람이 검수한 자료만 승인
  • 실패한 조합도 이유와 함께 저장
하지 않을 것
  • 단순 계산 한 줄까지 무조건 원자로 분리
  • AI가 만든 문제를 검수 없이 배포
  • 처리 문항 수 때문에 합의 기준을 낮춤
  • NGD2 통합을 프로젝트 성공 조건으로 삼음

최종 성공 기준은 간단합니다. 기출을 빠짐없이 분석하고, 원하는 난이도의 새 문제를 만들고, 수학강사가 검수해 실제 수업에 쓸 수 있는가.
